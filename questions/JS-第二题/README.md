成步堂律师正在调查一起案件。检察官提交了一系列证据，每份证据都有一个可信度评分，记录在整数数组 nums 中。

为了判断证据是否可靠，成步堂制定了一个标准：
如果连续一段证据中，最高评分与最低评分的差值不超过 k，那么这段证据就可以被认定为一组有效证据。

例如，证据评分为 [1, 3, 5]，当 k = 2 时：
- [1]：最高分与最低分之差为 0，符合条件。
- [1, 3]：最高分与最低分之差为 2，符合条件。
- [1, 3, 5]：最高分与最低分之差为 4，不符合条件。

现在，成步堂需要找出所有符合条件的连续证据组。

请你帮助成步堂统计，一共有多少组有效证据，并实现函数 countRecordSegments(nums, k)，返回符合条件的连续子数组数量。

异议！这次可不能漏掉任何一组关键证据！
